# Business Landing Page

A modern, responsive business landing page built with pure HTML, CSS, and JavaScript.

## Features

- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Image Gallery**: Showcase your work with a beautiful grid layout
- **Social Media Integration**: Links to all major social platforms
- **Smooth Scrolling**: Enhanced navigation experience
- **Mobile Menu**: Hamburger menu for mobile devices
- **Modern Animations**: Fade-in effects and smooth transitions

## Structure

```
Website/
├── index.html          # Main HTML file
├── css/
│   └── styles.css      # All styling and responsive design
├── js/
│   └── script.js       # Interactive functionality
├── images/             # Place your images here
└── README.md           # Documentation
```

## Customization

### 1. Update Content

Edit `index.html` to customize:
- Business name and logo
- Hero section text
- About section content
- Services offered
- Contact information

### 2. Add Images

Replace the placeholder images by:
- Adding your images to the `images/` folder
- Updating the HTML with `<img>` tags
- Example: `<img src="images/your-image.jpg" alt="Description">`

### 3. Update Colors

Edit the CSS variables in `css/styles.css`:

```css
:root {
    --primary-color: #2563eb;    /* Main brand color */
    --secondary-color: #1e40af;  /* Accent color */
    --text-color: #1f2937;       /* Body text */
    --text-light: #6b7280;       /* Secondary text */
    --bg-light: #f9fafb;         /* Light backgrounds */
}
```

### 4. Add Social Media Links

Update the social media links in the footer section of `index.html`:
- Replace `href="#"` with your actual social media URLs
- Supported platforms: Facebook, Twitter, LinkedIn, Instagram
